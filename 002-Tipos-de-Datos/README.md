# C# Desde Cero

## Capítulo 002 - Tipos de Datos

En C#, cada variable debe tener un tipo de dato.

El tipo determina qué clase de información puede almacenar una variable.

## Tipos básicos

| Tipo | Descripción | Ejemplo |
|------|-------------|---------|
| int | Números enteros | 25 |
| double | Números decimales | 1.78 |
| char | Un carácter | 'A' |
| string | Texto | "Hola" |
| bool | Verdadero o falso | true |

## Código

```csharp
int edad = 30;
double altura = 1.78;
char inicial = 'J';
string nombre = "Jonatan";
bool trabaja = true;
```

## Resultado esperado

```
=== TIPOS DE DATOS ===

Nombre: Jonatan
Edad: 30
Altura: 1.78
Inicial: J
¿Trabaja?: True
```
