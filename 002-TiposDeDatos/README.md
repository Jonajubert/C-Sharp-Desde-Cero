# Capítulo 002 - Tipos de Datos

## ¿Qué aprenderemos?

En C#, cada variable tiene un tipo de dato.

Ese tipo define qué información puede almacenar.

Algunos ejemplos son:

- string
- int
- double
- bool
- char

---

## Código

```csharp
string nombre = "Jonatan";
int edad = 30;
double altura = 1.75;
bool esProgramador = true;
char inicial = 'J';
```

---

## Resultado esperado

```
=== TIPOS DE DATOS ===

Nombre: Jonatan
Edad: 30
Altura: 1,75
¿Es programador?: True
Inicial: J
```

---

## ¿Por qué existen distintos tipos?

Cada tipo ocupa una cantidad diferente de memoria y está pensado para almacenar un tipo específico de información.

Elegir correctamente el tipo de dato mejora el rendimiento y evita errores.
